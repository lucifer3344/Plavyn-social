# Raw clips for reels

Drop site videos or iPhone/iPad screen recordings here (MP4 or MOV, any orientation; vertical is best).
Optional: add a line to `notes.txt` per file — `<filename> | what it shows | headline idea`.

The daily reel run uses these before falling back to app-screen animations:
it trims to at most 25 s, crops to 9:16, adds the Plavyn headline band and an end card, and writes a caption.
Used clips are listed in `reels/clips.json` (field `raw`) so they are never used twice.

Please only add footage you have the right to post. Blur or skip faces, client names and site boards
if the client hasn't agreed to be shown.
